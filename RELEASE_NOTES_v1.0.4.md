# v1.0.4 — RESS submission: full rerun, fixes and figures

Target journal changed from *Transportation Research Part C* to ***Reliability Engineering & System Safety***. Title: *Fleet-Assisted Risk-Threshold Recalibration with a Local Non-Bypass Guarantee for Connected Automated Vehicles*. Sole author: Mohammad Belayet Hossain.

**Fixes**
- `extra_experiments.py`: the clamp-free "federated mean" baseline now uses the mean aggregator, as documented. It reproduces under-protection 0.242; v1.0.3 printed 0.025 because the weighted aggregator was passed to every condition.
- `experiments.py`: restored the command-line entry point (`--seeds`, `--only`, `--real`). In v1.0.3 the script exited without running anything.
- `closed_loop.py`: now includes the Rob-FCP-style (trimmed-mean) baseline and **saves** `results_real/closed_loop.json`. In v1.0.3 it only printed, and the committed JSON came from an older version of the script.
- **Correction to the v1.0.3 notes:** the controlled naive fleet-clamp under-protection at 30% corrupted uploads is **0.080** (`results/C.json`). The v1.0.3 "correction" to 0.055 was wrong; 0.055 is the real-pool value.

**Results**
- Every JSON in `results/` and `results_real/` was regenerated by this release's scripts (see README). Stale certificate `bound` fields (≈0.056, pre-correction) are replaced by the corrected certificate (≈0.100).
- **Closed loop (Table 5) changes with the current code:**
  - collisions/1000 veh-steps: AEB 0.36, frozen 0.29, local-only 0.15, FedAvg 0.26, Rob-FCP 0.26, proposed 0.24;
  - under-protection: 0.038–0.053.
- **Removed** the stale intermediate `results_real/_reviewer_accum.json`.
- **Experiments E-G restored:** new `experiments_efg.py` regenerates `results_real/{E,F,G}.json` (adversarial-fraction sweep, aggregation period, shift heterogeneity) and the controlled versions in `results/`. The old files are kept in `results_real/legacy/` for comparison; the new runs agree with them to within seed noise. `closed_hetero.json` (no script, not used in the manuscript) is also kept there.
- `make_figures_ress.py` now plots Fig. 2, Fig. S3 and Fig. S4 from the regenerated E/F/G results, and labels the under-protection axis as "mean per-vehicle max." or "run-max." according to the metric.

**Figures**
- `make_figures_ress.py` replaces `make_figures_bw.py`. Figures use descriptive condition names, are black-and-white safe, have one y-axis per panel, and read all certificates from data. Output: `figures_ress/`. The old `figures/`, `figures_bw/` and `figures_real/` are removed.

**Known limitations (stated in the manuscript review, not changed here)**
- The fleet aggregator is a similarity-weighted **mean** of uploaded quantiles.
- The closed loop uses a 4-feature risk score.
- V2X delays shorter than one aggregation period (P·Δt = 2 s) have no effect by construction.
- `run_block.py`: runs on a fresh clone. v1.0.3 required a pre-existing `results_real/_bstar.json`, so `run_reviewer_experiments.py` failed at import.
- `run_ngsim.py`: no longer calls the missing Experiment E/F/G functions (it crashed in v1.0.3).
- `experiments.py` quick-look plots now use descriptive condition names.
- Timing (`timing.json`, this machine): about 16 µs per vehicle-step, including the amortized quantile recompute.

- **New `forensic_checks.py`** (supplementary Table S19): disjoint reference/stream halves of each real pool; paired seed-level closed-loop differences with sign-flip p-values; downward (over-intervention) fleet attack; empirical coverage of the retrospective per-step and simultaneous envelopes.
- `experiments_efg.py`: Experiment E now saves per-seed values and a paired sign-flip test (proposed, honest vs 30%/50% adversarial).
- `forensic_checks.py online`: valid on-vehicle (DKW) upper bound on the quantile modulus; reported as the online column of Table S18.
- New `REPRODUCIBILITY.md` (item → command → seeds → output) and `requirements-lock.txt` (exact versions, Python 3.11).
- `forensic_checks.py split70`: trajectory-level 70/30 split (streams from 70% of trajectories, B* only from the held-out 30%); `split` is the 50/50 version.
- `forensic_checks.py rho`: envelopes for operator-set drift bounds ρ = 0, 0.01, 0.02, 0.05 (supplementary Table S20).
- `forensic_checks.py robustclamp`: clamp reads a robust fleet aggregate (trimmed mean, median, Krum) under 0–50% adversarial uploads (Table 3 bottom rows).
- **Corrected** `forensic_checks.py online`: an upper DKW level above 1 now uses the known score support 1 instead of the sample maximum (which is not an upper confidence bound); adds a window-length sweep N_s = 300/600/1000/2000.
- `forensic_checks.py drift`: realized two-sided and one-sided drift between the window-averaged law and the current target for every studied shift, with the burn-in length.
- `forensic_checks.py online_sim`: simultaneous (all K·T vehicle-steps) rigorous online envelope vs window length.
- `forensic_checks.py closed8`: main closed loop re-run with the full eight-feature score of Eq. (1) (jerk by finite differences), with paired seed-level differences.
- Online envelopes: the quantile and DKW error budgets are now allocated jointly (per step α_q = α_DKW = 0.025; simultaneous α_q = α_DKW = ζ/(2KT)), so both are genuine 95% statements; retrospective envelopes unchanged.
- **Closed loop now uses the eight-feature score of Eq. (1)** in every closed-loop script (`closed_loop.py`, `deploy_experiments.py`, `scenarios.py`, `corridor.py`); `CL_SCORE=4` reproduces the earlier four-feature results (`*_4feat.json`, verified identical to the previous outputs). Corridor study now also runs the AEB reference.
- `forensic_checks.py`: `closed` (eight-feature) / `closed4` (ablation) paired tests; `deploy_paired` for the combined-fault test.
